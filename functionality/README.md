{% hint style="info" %}
#### Coins/Tokens accepted on the Marketplace

Both <mark style="color:red;">**$CFB**</mark> and <mark style="color:red;">**$Qubic**</mark> will be accepted on the Marketplace and both can be used by users to buy/sell NFTs on the secondary market.&#x20;

However, there are some exclusive functions reserved for each:

* Only <mark style="color:red;">**$Qubic**</mark> will be accepted for minting NFTs (primary market)
* On the other hand, <mark style="color:red;">**$CFB**</mark> will have a reserved exclusive function: the purchase of packages.
{% endhint %}
